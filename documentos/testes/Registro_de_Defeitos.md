# Registro de Defeitos – GymManager

## 1. Objetivo
Registrar e acompanhar os erros encontrados durante os testes do aplicativo.

## 2. Registro de problemas

| ID | Problema encontrado | Funcionalidade | Gravidade | Status |
|---|---|---|---|---|
| BUG01 | Nenhum erro registrado | - | - | Pendente de testes |

## 3. Classificação de gravidade

- **Baixa:** erro visual ou pequeno problema.
- **Média:** funcionalidade apresenta comportamento incorreto, mas existe alternativa.
- **Alta:** funcionalidade importante não funciona.
- **Crítica:** erro que impede o uso do sistema ou compromete dados.

## 4. Procedimento de registro

Para cada defeito encontrado, informar:
- Descrição do problema.
- Passos para reproduzir o erro.
- Resultado esperado.
- Resultado obtido.
- Gravidade do problema.

## 5. Observações

Os defeitos serão registrados conforme os testes forem executados e atualizados após as correções.
